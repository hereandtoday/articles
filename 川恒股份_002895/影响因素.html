川恒股份 · 影响因素

边界说明：本卡片聚焦"当前状态+边际变化+跟踪指标"，不含损失评估 - 损失评估/极端情景 → 风险 - 结构性威胁 → 风险

一、因素分类框架

核心逻辑：区分"改变公司赚钱能力的结构性因素"和"周期性波动的周期性因素"，判断哪些变化是永久性的、哪些是暂时性的。

区分标准：

维度 结构性因素 周期性因素
本质 不可逆地改变公司的量/成本结构/竞争地位 随经济周期、供需错配波动，均值回归
影响路径 改变产能规模、成本曲线位置、产品组合 改变产品售价、原料成本、短期利润率
时间跨度 3-10年持续影响，不随价格回摆 1-3年内随周期波动，均值回归
投资含义 决定长期价值中枢 决定短期买卖时机

川恒股份的因素画像： - 结构性因素 6 项：产能扩张 + 成本结构升级 + 固定资产重塑 + 股权激励解禁 + 矿权归属分散化 → 共同改变公司"能赚多少钱的能力" - 周期性因素 3 项：磷矿石价格 + 硫磺价格 + 新能源需求 → 共同影响"短期赚多赚少" - 混合因素 1 项：磷酸铁扩产（结构性投资 vs 周期性需求窗口）

二、结构性因素（改变赚钱能力）

结构性因素一旦落地，不可逆转。它们共同决定了公司未来3-5年的利润中枢。

F1：磷矿产能大扩张（核心结构性变化）

影响路径：量增 → 收入增厚 + 毛利扩张

  • 变化内容：【L2】2027-2028年磷矿总产能从300万吨/年扩张至1230万吨/年（并表，+310%），权益产能从~270万吨扩至~895万吨（+231%）
  • 鸡公岭磷矿（福麟矿业90%，250万吨/年，权益225万吨）：2027年下半年投产
  • 老寨子磷矿（黔源地勘58.5%，180万吨/年，权益105万吨）：2027年底投产
  • 老虎洞磷矿（天一矿业49%参股，500万吨/年，权益245万吨）：2027年左右投产
  • 小坝技改（福麟矿业90%，+30万吨，权益+27万吨）：2027年6月（可能提前）
  • 对业绩的影响：
  • 收入端：新增磷矿石外销+自用比例提升→中游产品成本下降
  • 利润端：产能利用率爬坡后，规模效应摊薄固定成本，净利润弹性最大年份在2027年
  • 毛利率：转固后短期承压（折旧增加），中期随产能利用率提升修复
  • 时效性：中期（2027年集中投产，2028年达产）
  • 当前状态：→ 建设推进中，2026年工程矿量不大（管理层明确）
  • 权益产能注意：【L4】新增产能分散在三个主体，权益产能仅为并表的73%。老虎洞（500万吨）以权益法计入，不并表不贡献营收。

F2：硫酸供应链战略转型（成本护城河重塑——最重要的结构性变化）

影响路径：从"被动防御"到"主动控本" → 成本曲线结构性左移

  • 变化内容：【L2】公司在磷矿石基本自给后，核心成本变量已转移至硫资源。当前正执行从"依赖外购冶炼酸"向"大幅提升自有硫铁矿制酸"的战略转型：
  • 现状（2025-2026）：年度硫酸总需求约240万吨。自产产能50万吨/年（硫铁矿制酸30万吨满负荷+硫磺制酸20万吨仅维持热能平衡），外购冶炼酸~190万吨（80%+）。硫铁矿制酸原料（硫精砂）为外购。
  • 2027年拐点：贵州+广西两套新硫铁矿制酸装置投料（4月/5月），自产产能从50→90万吨/年，全部为硫铁矿制酸，占比从~12%→~38%
  • 战略收缩：原规划40万吨硫磺制酸项目（投资2亿元）已暂停——公司战略性放弃高成本路线

  • 柔性供应链：未来在自产硫铁矿制酸+外购冶炼酸间动态平衡，始终选择成本最优组合

  • 对业绩的影响：

  • 成本端（结构性）：据公司交流口径，硫铁矿制酸较硫磺制酸节约~500元/吨，外购冶炼酸较硫磺制酸节约300-400元/吨，边际成本差异仅100-200元/吨。自产产能扩至90万吨后，年度直接节约约1.4-2.4亿元（占2025净利润11%-19%）。核心价值在于供给自主可控，而非单纯降本
  • 利润端：硫磺价格每波动100美元/吨，对2027年后利润的冲击幅度较当前减半
  • 护城河：成本优势从"磷矿自给"单引擎升级为"磷矿+硫资源"双引擎，系统性压榨纯外购企业利润空间

  • 期权价值：磷石膏制酸技术论证中，若突破将进一步打开硫资源自给想象空间

  • 时效性：中期（2027年4-5月为关键拐点）

  • 当前状态：建设推进中，40万吨硫磺制酸已暂停

F3：在建工程转固（资产负债表重塑）

影响路径：资产结构变化 → 折旧增加 + 利息费用化

  • 变化内容：【L2】鸡公岭、老寨子、老虎洞等项目处于建设或即将投产阶段，2026-2028年大规模转固
  • 对业绩的影响：
  • 短期：固定资产折旧大幅上升（压制毛利率1-2pct），在建工程利息费用化处理
  • 中期：若产能利用率不足60%，折旧压力将持续压制ROE
  • 长期：转固完成后进入稳态，折旧占收入比例随规模效应下降
  • 时效性：中期（2026-2028年分批转固）
  • 当前状态：→ 建设推进中，需跟踪转固节奏

F4：股权激励解禁（微弱结构性）

影响路径：股本扩张 → EPS稀释（极微）

  • 变化内容：【L2】2026年6月15日461.62万股股权激励解禁，占总股本不足0.5%
  • 对业绩的影响：
  • EPS影响：减持规模约1.62亿元，占总市值0.76%，对EPS影响可忽略
  • 筹码影响：短期筹码压力极小
  • 时效性：短期（一次性事件）
  • 当前状态：→ 短期筹码压力可忽略

F9：矿权归属分散化（利润归属结构性变化）

影响路径：新矿不在福麟矿业 → 利润贡献比例分散

  • 变化内容：【L2】当前福麟矿业（川恒持股90%）贡献公司净利润约67%（2025年8.50亿/12.60亿）。但2027年投产的三大新矿分属不同主体：
  • 老寨子（黔源地勘58.5%）→ 并表但少数股东占41.5%
  • 老虎洞（天一矿业49%）→ 不并表，仅投资收益
  • 鸡公岭（福麟矿业90%）→ 全额并表
  • 对业绩的影响：
  • 福麟矿业利润占比将从67%显著下降（老寨子/老虎洞投产后）
  • 公司整体矿端利润总额大幅增长，但归母净利增速低于并表利润增速（少数股东分走更多）
  • 老虎洞500万吨产能虽大，但仅以49%权益法计入，利润弹性打折
  • 时效性：中期（2027年三大矿投产后生效）
  • 当前状态：→ 建设中，尚未影响

三、周期性因素（短期赚多赚少）

周期性因素随价格波动，均值回归。它们决定短期利润率在利润中枢上下波动的幅度。

F5：硫磺价格（当前最大利空）

影响路径：原料成本波动 → 毛利率短期剧烈波动

  • 变化内容：【L2】2025Q4起受中东地缘政治+供需错配影响，硫磺价格大幅上涨。当前采取极限"工艺套利"策略——将硫磺制酸负荷降至最低（仅维持热能平衡），高度依赖外购冶炼酸（80%+）。但冶炼酸价格仍随硫磺波动，80%外购占比无法完全免疫产业链通胀传导
  • 量化影响：
  • 2025Q4：归母净利润环比-31%，毛利率环比-6pct
  • 2026Q1：归母净利润环比继续-36%，毛利率阶段性承压至25.07%
  • 预计2026年毛利率触底至~27%
  • 缓冲机制：
  • 短期：2026年4月提价500-600元/吨（部分传导）；三套酸切换方案
  • 中期：2027年硫铁矿制酸投产后（F2），冲击幅度将永久性收窄
  • 时效性：短期核心压制因素，2027年为基本面反转拐点
  • 当前状态：↓ 边际恶化，但提价传导已启动
  • 与结构性因素的交互：F2（硫酸供应链转型）是F5的"解药"——90万吨/年硫铁矿制酸能力投产后，公司对硫磺价格的敏感度将系统性下降

F6：磷矿石价格

影响路径：产品售价波动 → 利润弹性放大器

  • 变化内容：【L2】磷矿石价格自2022年高点以来持续回落
  • 量化影响：
  • 磷矿石自用比例提升后，价格波动对成本端的冲击减小（自供锁定成本）
  • 外销磷矿石价格下跌直接减少收入和毛利
  • 对中游产品（磷酸、MCP）定价有传导效应
  • 时效性：价格调整期可能持续至2026年
  • 当前状态：↓ 但进一步大幅下跌空间有限（成本支撑）
  • 与结构性因素的交互：产能扩张（F1）后外销量增加，价格敏感度提高

F7：新能源需求（磷酸铁需求端）

影响路径：下游需求波动 → 磷酸铁量价齐升或量增价跌

  • 变化内容：【L2】受益于新能源车和储能需求，磷酸铁锂需求持续增长，但增速和价格存在波动
  • 量化影响：
  • 需求景气时：磷酸铁满产满销，毛利率回升，收入翻倍
  • 需求低迷时：磷酸铁价格承压，以量补价，毛利率难以扩张
  • 时效性：周期性波动，与新能源行业景气度高度相关
  • 当前状态：→ 行业尾部产能出清中，价格底部企稳迹象
  • 与结构性因素的交互：成本第一梯队优势（8000-9000元/吨）使公司在行业低谷期仍可盈利，周期底部是扩产抢占份额的最佳窗口

四、混合因素（结构性投资 × 周期性窗口）

F8：磷酸铁翻倍扩产

影响路径：结构性产能扩张 × 周期性需求窗口 → 第三曲线利润弹性

  • 变化内容：【L2】2026年磷酸铁产能从10万吨扩至25万吨（+150%），分两批投放（年初5万吨+年中10万吨）
  • 结构性维度：
  • 产能翻倍是不可逆的投资，改变公司产品组合和收入结构
  • 成本第一梯队优势（8000-9000元/吨）是结构性壁垒，非周期性
  • 净化磷酸自给（10万吨/年）是结构性成本优势
  • 周期性维度：
  • 投产时机选择与行业周期高度相关——在行业尾部扩产，目的是抢占出清后的市场份额
  • 磷酸铁价格能否企稳取决于新能源需求周期
  • 产能利用率爬坡节奏受需求周期影响
  • 对业绩的影响：
  • 若行业价格企稳：磷酸铁收入有望翻倍至15亿+，成为重要利润来源
  • 若行业持续低迷：以量补价，收入增长但利润贡献有限
  • 时效性：中短期（2026年分批投产）
  • 当前状态：↑ 已验证满产满销，成本第一梯队

五、结构性 vs 周期性：对业绩的影响机制

5.1 利润驱动分解

净利润 = 量 × 价 - 成本
         │     │     │
         │     │     └── 周期性（硫磺F5/磷矿石F6）+ 结构性（F2硫铁矿制酸降成本）
         │     └── 周期性（磷矿石F6/磷酸铁F7）+ 结构性（F1产能释放增加外销量）
         └── 结构性（F1产能扩张）+ 周期性（F7需求景气度）
利润驱动因子 结构性贡献 周期性贡献
量（收入规模） F1产能扩张（并表300→1230万吨/权益270→895万吨）+ F8磷酸铁扩产（10→25万吨） F7新能源需求景气度影响磷酸铁开工率
价（产品售价） MCP寡头地位支撑定价权 磷矿石F6价格波动 + 磷酸铁F7价格波动
成本（原料+制造） F2硫铁矿制酸降本 + 磷矿自给率提升 硫磺F5价格波动（当前最大成本变量）

5.2 不同情景下的利润归因

情景 结构性因素贡献 周期性因素贡献 净利润预期
乐观（磷矿石900+，硫磺回落，新能源景气） 产能释放+成本改善 价格上行+需求旺盛 20+亿（2027E）
基准（磷矿石800，硫磺高位，需求平稳） 产能释放+成本改善 价格中性+需求平稳 15-17亿（2027E）
悲观（磷矿石<800，硫磺持续暴涨，需求低迷） 产能释放（量增对冲价跌） 价格下行+成本高企 10-12亿（2027E）

关键结论：【L4】结构性因素（产能扩张为主+边际成本改善约1.4-2.4亿/年）决定利润中枢从12.6亿（2025A）向15-20亿（2027E）上移；周期性因素（硫磺/磷矿石/新能源价格）决定在这个中枢上下±30%的波动幅度。产能扩张是利润增长的绝对核心，硫酸供应链转型的直接利润贡献有限但提供供给安全边际。
