二、边际变化分析

2.1 煤炭价格（F1）

当前状态：🟡 关注（煤价处于低位，H2已出现修复迹象）

【L2】2025年秦港动力煤价约697元/吨，京唐港主焦煤均价约1513元/吨，均跌至近年来低位。2026年1-2月煤炭开采和洗选业固定资产投资增速已环比改善。

影响路径：煤价下跌 → 煤企利润下降 → 资本开支减少 → 煤机订单承压 → 毛利率下降

边际变化：2026年以来煤价已出现一定修复区间，"反内卷"政策导向叠加保供需求有望支撑煤价底部改善。

后续跟踪：秦港动力煤价格月度数据，跌破600元/吨则警示。

2.2 汽车行业景气度（F2）

当前状态：🟢 正面（新能源转型带来结构性机会）

【L2】亚新科商用车配套稳健，乘用车领域产品从拉杆延伸至摆臂、副车架等底盘部件，空气悬架部件、热管理系统冷板、底盘副车架部件等新业务拓展顺利。

影响路径：汽车行业景气度提升 → 汽零订单增加 → SEG/SES/亚新科盈利能力改善

边际变化：2025年汽车行业整体承压，但新能源转型带来结构性机会，SES收入+201%验证高增长逻辑。

2.3 新能源汽车渗透率（F3）

当前状态：🟢 正面（SES直接受益）

【L2】SES成功获得EMB刹车电机项目，实现底盘域电机业务突破；800V高压扁线胶粘定转子产品成功量产。

影响路径：新能源渗透率提升 → 驱动电机需求增加 → SES订单放量 → SES收入高增长

边际变化：2025年SES收入7.8亿元同比+201%，2026年目标突破15亿元。

2.4 工业智能渗透率（F4）

当前状态：🟢 正面（百亿目标明确）

【L2】工业智能板块2025年收入33.31亿元，同比+22%，净利润9.4亿元，净利率28.2%，盈利质量优异。从矿山向船舶、钢构等离散制造场景复制。

影响路径：工业智能渗透率提升 → 公司订单增加 → 收入和利润高增长 → 百亿目标实现

边际变化：2025年已获取多个跨行业标杆项目，恒达智控入选工信部多项名录，可转债发行若落地将加速产能扩张。

2.5 SES新能源电机放量（F5）

当前状态：🟢 正面（高速成长期）

【L2】2025年SES新能源电机实现收入7.8亿元，同比大增201%，进入高速成长期。

影响路径：SES放量 → 汽零板块利润贡献增加 → 整体盈利能力提升 → 估值重塑

边际变化：EMB刹车电机项目获定点，800V高压扁线电机量产，从代工向自主研发转型。

后续跟踪：SES季度收入增速，同比增速低于50%则下调预期。

2.6 可转债发行进度（F6）

当前状态：🟡 待定（预计Q2-Q3落地）

【L2】公司拟发行A股可转债（投向工业智能业务扩产），可转债发行若顺利落地，将为工业智能板块提供充足资金支持，加速产能建设。

影响路径：可转债发行 → 工业智能资金充足 → 产能扩张加速 → 收入高增长

边际变化：发行预案落地时间，预计2026年Q2-Q3。
