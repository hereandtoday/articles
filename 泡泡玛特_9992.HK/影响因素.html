二、边际变化分析

2.1 Labubu热度（F1）

当前状态：🟡 关注（从高峰期回落，2025年高点335港元已回撤50%）

【L2】Labubu（THE MONSTERS）成为首个百亿级IP，2025年收入占比约38%。2025年股价高点335.4港元已回撤超50%，体现周期属性。

影响路径：Labubu热度下降 → 毛绒品类增速放缓 → 整体营收增速回落 → 估值承压

边际变化：2026年4月30日乐园1.5期重磅升级开业，可能带动短期热度回升。

后续跟踪：Labubu二手市场价格指数，月度社交媒体声量数据。

2.2 新IP市场接受度（F2）

当前状态：🟡 待验证（Merodi 2026年2月发布，KeyA 2026年3月发布）

【L2】2025年发布57个新IP，Supertutu市场反响平淡。Merodi和KeyA是IP梯队接续的关键观察窗口。

影响路径：新IP验证成功 → IP梯队接续 → 单一IP依赖降低 → 估值重塑

边际变化：3-6个月内评估Merodi/KeyA是否能进入公司收入过亿IP清单。

后续跟踪：社交媒体声量，销量数据，是否进入收入过亿IP清单。

2.3 情绪消费行业景气（F3）

当前状态：🟢 正面（中国情绪经济市场规模2.7万亿元，持续扩容）

【L2】中国情绪经济市场规模2.7万亿元（2025年），预计2029年达4.6万亿元。潮玩作为情绪消费的核心品类具备持续扩容的宏观背景。

影响路径：情绪消费扩容 → 潮玩行业增长 → 泡泡玛特受益

边际变化：宏观消费复苏进度，情绪经济渗透率提升。

2.4 海外市场文化接受度（F5）

当前状态：🟢 正面（美洲爆发+748.4%，欧洲仅3.9%空间大）

【L2】美洲2025年收入68.06亿元同比+748.4%，欧洲占比仅3.9%说明仍处开拓早期，空间巨大。

影响路径：海外消费者接受度提升 → 海外收入高增长 → 全球化和IP平台化逻辑验证

边际变化：2026年目标海外200+家新店，欧洲/美洲渗透率提升。

2.5 海外门店扩张进度（F6）

当前状态：🟢 正面（2025年海外收入占比43.8%，持续提升）

【L2】2025年海外收入占比43.8%，较2024年的38.85%进一步提升。630家门店（欧洲36家），2026年目标新增200+家海外门店。

影响路径：海外门店增加 → 海外收入增加 → 全球化和IP平台化逻辑验证

边际变化：月度新开店数量，季度区域收入增速。
